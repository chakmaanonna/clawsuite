## 📋 What is clawsuite?

clawsuite is a desktop app designed to help you manage OpenClaw agents. Think of it as a control center where you can easily see, organize, and control your AI agents. This tool works smoothly on your computer and simplifies tasks that would otherwise require technical skills.

The app is built with modern technologies like React and Tauri, making it fast and reliable. You don’t need to know how to code to use clawsuite. Its simple interface lets you get started quickly with your agents.

## 💻 System Requirements

Before you download clawsuite, make sure your computer meets these basic requirements:

- **Operating System:** Windows 10 or later, macOS 10.14 or later, or most Linux distributions released in the last 5 years.
- **Processor:** 1.5 GHz or faster (Intel or AMD).
- **Memory:** At least 4 GB of RAM.
- **Disk Space:** Minimum 500 MB free space.
- **Internet:** Required only for downloading and updates.

If you have any recent standard laptop or desktop, clawsuite will run without issues.

## 🚀 Getting Started with clawsuite

When you open the app for the first time, you will see a dashboard with your agents.

### Add Your First Agent

1. Click the "Add Agent" button.
2. Enter a name for your agent.
3. Choose the type of OpenClaw agent you want to control.
4. Customize settings such as behavior and resource limits.
5. Click "Save" to add your agent to the list.

### Manage Agents

Here’s what you can do with your agents inside the app:

- **Start or Stop agents:** Use the power buttons next to each agent.
- **Monitor activity:** See status updates and agent performance.
- **Edit Settings:** Change how an agent behaves or update its resources.
- **Remove Agents:** Delete agents you no longer need with a single click.

## 🛠 Troubleshooting Tips

If you run into problems, try these steps:

- Make sure your operating system is up to date.
- Check that you downloaded the correct installation file for your system.
- Restart your computer after installation.
- Quit and reopen clawsuite if it stops responding.
- Verify that your agents are configured correctly within the app.
- If an agent won’t start, review its log for error messages in the app.

If issues continue, visit the GitHub issues page for help or report your problem there.
